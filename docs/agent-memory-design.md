# Agent、记忆与 Skill Pack

Agent 是受控状态机，不是无边界自主代理。它只能读取岗位模型、检索当前候选人简历/面试证据、检测冲突、计算规则分和生成待确认草稿；服务端用 Zod 校验参数，最多 6 步，单步 12 秒、总计 45 秒、最多重试 2 次。模型不能调用“录用/淘汰”工具。

短期记忆包含当前面试的最近对话和滚动摘要；长期记忆包含已确认岗位模型、候选人证据和 HR 修订历史。所有检索以 `organizationId + jobId + applicationId` 作为硬过滤条件，跨候选人召回在数据层被阻断。

Skill Pack 是版本化业务配置：胜任力词典、Rubric、面试策略、Prompt 片段、工具白名单、评测规则。首版内置通用 PM、AI PM、财务 AI PM。版本随 Assessment 保存，保证结论可复现。
