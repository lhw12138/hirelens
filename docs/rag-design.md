# RAG 决策记录

## 方案

文档按简历章节切分，保留页码、段落、字符范围和脱敏原文。召回分数为关键词 BM25/tsvector、pgvector 余弦相似度和业务字段匹配的融合结果，再由 `qwen3-rerank` 重排。评审只接收当前岗位、当前申请和 Top-K 证据。

## 为什么不是全量 Prompt

全量输入成本高、定位弱，且会让不同段落的无关经历干扰评分。RAG 可以证明某条结论来自哪里，也能独立测量召回覆盖率。关键词检索保住专有名词，向量检索处理同义表达，重排优化最终上下文。

## 失败策略

Top-K 没有达到阈值时返回“证据不足”；简历与面试答案冲突时同时保留两条引用，交给 HR 核实；向量服务失败时降级关键词检索并在 Trace 标记，不悄悄用模型常识补写经历。
